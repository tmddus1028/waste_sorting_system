# 5. Implementation Requirements

본 시스템은 AI 기반 쓰레기 분류 기능, 재활용 정보 검색 기능, 지역별 분리배출 규칙 조회 기능, 로그인 및 관리자 기능을 제공하는 웹 기반 시스템이다. 시스템 구현을 위해 프론트엔드, 백엔드, AI 모델 서버, 데이터베이스 연동 환경이 필요하다.

본 프로젝트는 프론트엔드와 백엔드가 분리된 구조로 구현되었다. 프론트엔드는 사용자의 이미지 업로드, 로그인, 결과 조회, 재활용 정보 검색 화면을 담당하고, 백엔드는 업로드된 이미지를 AI 모델로 분석하여 쓰레기 종류를 예측한다. 또한 Supabase를 이용하여 사용자 정보, 분석 결과, 품목별 가이드, 지역별 규칙 데이터를 관리한다.

---

## 1) H/W Platform Requirements (하드웨어 플랫폼 요구사항)

| 항목 | 권장 사양 | 비고 |
| :--- | :--- | :--- |
| **CPU** | Intel Core i5 이상 권장 | 시스템 연동 및 웹 서버 구동용 |
| **RAM** | 8GB 이상 권장 | 데이터 처리 및 모델 로딩 |
| **HDD / SSD** | 10GB 이상의 여유 공간 권장 | OS, 개발 환경, 모델 파일 저장용 |
| **GPU** | NVIDIA GPU 권장 | 필수는 아니지만, AI 모델 학습 및 빠른 이미지 예측을 위해 권장 |
| **Network** | 인터넷 연결 필수 | Supabase 데이터베이스 및 공공 API 연동 |

<br>

## 2) S/W Platform Requirements (소프트웨어 플랫폼 요구사항)

| 구분 | 항목 | 사양 / 기술 스택 |
| :--- | :--- | :--- |
| **기본 환경** | OS | Microsoft Windows 10 이상 권장 |
| | Web Browser | Chrome, Microsoft Edge 등 최신 웹 브라우저 |
| **개발 언어** | Frontend | HTML, CSS, JavaScript |
| | Backend | Python |
| **프레임워크 / 라이브러리** | Frontend Runtime / Framework | Node.js, Vite |
| | Backend Framework | FastAPI, Uvicorn |
| | AI Model Library | Ultralytics YOLO, PyTorch |
| | Image Processing Library | Pillow |
| **데이터 및 인증** | Database / Authentication | Supabase, PostgreSQL |

## 3) Development Environment (개발 및 구동 환경)

* **Frontend Development Tool:** Visual Studio Code
* **Backend Development Tool:** Visual Studio Code
* **Package Manager:** `npm` (Frontend), `pip` (Backend)
* **Backend Server Port:** `127.0.0.1:8000`
* **Frontend Server:** Vite 개발 서버 사용
* **Model File:** `backend/model/best.pt`
