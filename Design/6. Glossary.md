# 6. Glossary

본 시스템의 구현 및 운영에 사용되는 주요 기술 및 개념에 대한 설명입니다.

---

### 1. Supabase
* **정의:** 데이터베이스, 로그인, 회원가입, 사용자 인증 기능을 제공하는 백엔드 서비스 플랫폼(BaaS, Backend as a Service)입니다.
* **시스템 내 역할:** 본 시스템에서는 사용자 계정 관리, 분석 결과 저장, 관리자 데이터 관리 등에 사용됩니다.

### 2. API (Application Programming Interface)
* **정의:** 서로 다른 프로그램이나 서비스가 규칙에 따라 데이터를 주고받기 위한 통신 방식이자 인터페이스입니다.
* **시스템 내 역할:** 본 시스템에서는 프론트엔드가 백엔드에 이미지 분석 요청을 보내거나, 백엔드가 외부 공공데이터포털 등의 재활용 정보를 가져올 때 사용됩니다.

### 3. YOLO (You Only Look Once)
* **정의:** 이미지 인식 및 객체 탐지(Object Detection)에 널리 사용되는 초고속·고성능 딥러닝 인공지능 모델입니다.
* **시스템 내 역할:** 사용자가 업로드한 쓰레기 이미지를 실시간으로 분석하여 어떤 종류의 폐기물(플라스틱, 캔, 종이 등)인지 항목을 예측하는 데 사용됩니다.

### 4. CRUD (Create, Read, Update, Delete)
* **정의:** 대부분의 소프트웨어가 가지는 기본 데이터 처리 기능인 **생성(Create), 조회(Read), 수정(Update), 삭제(Delete)**의 약자입니다.
* **시스템 내 역할:** 본 시스템에서는 관리자가 시스템 백 오피스에서 재활용 정보나 지역별 분리배출 규칙 데이터를 추가, 조회, 수정, 삭제하며 관리할 때 사용됩니다.

### 5. Node.js
* **정의:** 브라우저 내부에서만 동작하던 JavaScript를 브라우저 외부(서버 측 등)에서도 실행할 수 있도록 해주는 런타임(실행 환경)입니다.
* **시스템 내 역할:** 본 시스템에서는 프론트엔드 개발 서버(Vite)를 구동하고, 필요한 외부 패키지 및 라이브러리(npm)를 관리하는 데 사용됩니다.
