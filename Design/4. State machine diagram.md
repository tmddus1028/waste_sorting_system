회원가입 또는 로그인을 한 뒤 사용자의 권한에 따라 사용할 수 있는 기능이 나누어진다. 일반 사용자는 로그인 후 이미지 업로드, AI 쓰레기 분류 요청, 분석 결과 확인, 상세 분리배출 가이드 조회, 재활용 정보 검색, 지역별 분리배출 규칙 조회 기능을 사용할 수 있다. 관리자는 일반 사용자 기능 외에도 관리자 대시보드에 접근하여 재활용 관련 데이터를 추가, 수정, 삭제하는 CRUD 기능을 수행할 수 있다. 사용자가 이미지를 업로드하면 클라이언트는 서버의 /predict API로 분석을 요청하고, 서버는 YOLO 모델을 이용해 이미지를 분류한 뒤 신뢰도를 판단하여 결과와 분리배출 안내를 응답한다. 또한 사용자가 재활용 정보를 검색하면 서버는 공공데이터 API를 호출하고 JSON/XML 데이터를 정리한 뒤 검색 결과를 클라이언트 화면에 출력한다. 서버는 실행 시 모델 파일을 확인하고, 모델이 정상적으로 로딩되면 API 요청을 대기하는 상태로 전환된다.
