# 4. User Interface prototype
본 시스템은 사용자가 쉽고 직관적으로 쓰레기 분리배출 정보를 확인할 수 있도록 간단하고 명확한 사용자 인터페이스를 제공한다.   
각 화면은 사용자의 주요 기능 흐름(회원가입 → 로그인 → 이미지 업로드 → 결과 확인)을 중심으로 구성된다.


##  4.1 Main Screen
<img width="2874" height="1490" alt="image" src="https://github.com/user-attachments/assets/ebce4202-c9f2-445f-8b02-141939338e4c" />
메인 화면은 사용자가 시스템에 처음 접속했을 때 표시되는 첫 화면이다. 

사용자는 이 화면에서 시스템의 주요 기능을 한눈에 확인할 수 있다. 
화면 상단에는 홈, 가이드, 지역별 규칙, 재활용 정보검색 메뉴가 배치되며, 주요 기능 영역에는 사진 업로드, 재활용 정보 검색, 지역별 규칙 조회 기능이 카드 형태로 제공된다.
사용자는 회원가입 후 로그인하여 쓰레기 이미지 업로드 기능을 사용할 수 있다. 
또한 재활용 정보 검색과 지역별 분리배출 규칙 조회 기능은 메인 화면에서 바로 접근할 수 있도록 구성되어 있어 원하는 기능을 빠르게 선택할 수 있다.

**사용방법**  
1. 로그인 또는 회원가입 후 모든 기능을 이용할 수 있습니다.
2. 검색 및 지역별 규칙 조회는 로그인 없어도 가능합니다.

## 4.2 Register Screen
<img width="1330" height="1434" alt="image" src="https://github.com/user-attachments/assets/130c8333-7f42-49e4-959e-fb8ea7d5091d" />

회원가입 화면은 새로운 사용자가 시스템을 이용하기 위해 계정을 생성하는 화면이다. 

사용자는 이름, 이메일, 비밀번호,비밀번호 확인을 입력하여 회원가입을 진행한다. 입력한 이메일은 로그인 ID로 사용되며, 비밀번호는 사용자 인증을 위해 사용된다.

사용자가 모든 정보를 입력하고 회원가입 버튼을 클릭하면 시스템은 입력값의 형식과 중복 여부를 확인한다. 
이메일 형식이 올바르지 않거나 이미 가입된 이메일인 경우 오류 메시지를 표시하고 다시 입력하도록 안내한다. 
회원가입이 정상적으로 완료되면 로그인 화면으로 이동한다.

**사용방법**  
1. 이름,이메일,비밀번호,비밀번호 확인을 입력합니다
2. 회원가입 버튼을 클릭합니다.
3. 가입이 완료되면 로그인화면으로 이동합니다.

## 4.3 Login Screen
<img width="1154" height="1212" alt="image" src="https://github.com/user-attachments/assets/17f3e56a-6132-404f-96f4-67d000f4820c" />
로그인 화면은 등록된 사용자가 시스템에 접속하기 위해 인증을 수행하는 화면이다. 사용자는 이메일과 비밀번호를 입력한 뒤 로그인 버튼을 클릭한다.

시스템은 Supabase Auth를 통해 입력된 이메일과 비밀번호를 인증한다. 인증이 성공하면 profiles 테이블에서 사용자의 권한 정보를 조회한다. 일반 사용자는 메인 화면으로 이동하고, 관리자 권한을 가진 사용자는 관리자 데이터 관리 화면으로 이동한다. 인증에 실패하면 로그인 실패 메시지를 표시한다.

**사용방법**  
1.  이메일과 비밀번호를 입력합니다
2. 로그인 버튼을 클릭합니다
3. 인증이 성공하면 메인 서비스 화면으로 이동합니다.


## 4.4 Upload Waste Image Screen
<img width="1512" height="1388" alt="image" src="https://github.com/user-attachments/assets/83146192-526d-4229-b39c-3688fd433614" />
이미지 업로드 화면은 사용자가 분리배출 방법을 알고 싶은 쓰레기 사진을 등록하는 화면이다. 

사용자는 카메라를 이용해 즉시 사진을 촬영하거나, 기존에 저장된 이미지 파일을 선택하여 업로드할 수 있다.

업로드 가능한 파일 형식은 JPG, PNG 등의 이미지 파일로 제한한다. 사용자가 이미지를 선택하고 업로드 버튼을 클릭하면 시스템은 해당 이미지를 서버로 전송한다. 
이후 이미지 인식 기능을 통해 쓰레기의 종류를 자동으로 분석한다. 파일 형식이 올바르지 않거나 이미지가 선택되지 않은 경우 오류 메시지를 표시한다. 또한 AI 분석 신뢰도가 낮거나 품목을 명확히 식별하기 어려운 경우, 사용자가 다시 촬영하거나 다른 이미지를 업로드하도록 안내한다.

**사용방법**  
1. 카메라 촬영 또는 파일 선택을 합니다.
2. 업로드 버튼을 클릭하면 분석이 시작됩니다.


## 4.5 Result Screen
<img width="1246" height="1254" alt="image" src="https://github.com/user-attachments/assets/86156eb8-640e-46da-9e46-6af148469f94" />
결과 화면은 업로드된 이미지 분석 결과를 사용자에게 보여주는 화면이다. 시스템은 식별된 쓰레기 품목명, 재활용 가능 여부 또는 확인 필요 상태, 기본 분리배출 방법을 화면에 표시한다.

예를 들어 플라스틱으로 식별된 경우, 내용물을 비우고 필요한 경우 라벨이나 뚜껑을 분리한 뒤 배출하도록 안내한다. 사용자는 이 화면에서 기본적인 분리배출 방법을 확인할 수 있으며, 더 자세한 정보가 필요한 경우 상세 가이드 보기 버튼을 선택할 수 있다.


**사용방법**  
1. 시스템이 분석한 쓰레기 종류와 재활용 가능여부를 확인합니다.
2. 분리배출 방법을 확인합니다.
3. 더 자세한 정보가 필요하면 상세가이드 보기를 클릭합니다.


## 4.6 Detailed Guide Screen
<img width="948" height="1498" alt="image" src="https://github.com/user-attachments/assets/25909c86-473c-4903-8a17-5ef23bcd5d22" />
상세 가이드 화면은 기본 결과 화면보다 더 구체적인 분리배출 방법을 제공하는 화면이다. 이 화면에서는 품목별 세척 방법, 분리 방법, 배출 방법, 주의사항 등을 자세히 안내한다.

예를 들어 플라스틱류의 경우 내용물을 비우는 방법, 라벨 제거 여부, 뚜껑 분리 여부 등을 단계별로 확인할 수 있다. 또한 오염이 심한 경우처럼 일반적인 재활용 기준과 달라질 수 있는 상황에 대한 주의사항도 함께 제공한다.

**사용방법**  
상세한 분리배출방법과 주의사항을 확인합니다.

## 4.7 Search Recycling Information Screen
<img width="1064" height="1526" alt="image" src="https://github.com/user-attachments/assets/6370049b-bd7a-43d5-8573-fa9d954a2ac1" />
재활용 정보 검색 화면은 사용자가 이미지 업로드 없이 직접 품목명을 입력하여 재활용 정보를 찾는 화면이다. 사용자는 검색창에 종이, 플라스틱, 캔, 유리 등 확인하고 싶은 품목명을 입력한다.

시스템은 입력된 검색어와 관련된 재활용 정보를 검색하여 결과를 표시한다. 사용자는 검색 결과를 통해 재활용 가능 여부와 배출 방법을 확인할 수 있다. 검색 결과가 없는 경우에는 다른 검색어를 입력하도록 안내 메시지를 제공한다.

**사용방법**  
1. 검색어를 입력하고 검색버튼을 클릭합니다
2. 검색 결과에서  품목의 재활용 가능 여부와 배출 방법을 확인합니다.

## 4.8 Check Local Recycling Rules Screen
<img width="1336" height="1510" alt="image" src="https://github.com/user-attachments/assets/77dd634d-5aed-4948-b2d4-ef1a1dfba654" />
지역별 분리배출 규칙 화면은 사용자가 자신의 거주 지역에 맞는 분리배출 기준을 확인하는 화면이다. 

사용자는 지역 선택 메뉴에서 시, 군, 구 단위의 지역을 선택한다.

시스템은 선택된 지역의 수거 요일, 배출 시간, 배출 장소 등의 정보를 표시한다. 지역마다 분리배출 기준이 다를 수 있으므로, 이 화면은 사용자가 자신의 지역 규칙에 맞게 쓰레기를 배출하도록 돕는 역할을 한다.

**사용방법**  
1. 시/도와 시/군/구를 선택합니다.
2. 선택한 지역의 수거 요일, 배출 시간, 배출 장소를 확인합니다.

## 4.9 Admin Data Management Screen
<img width="2530" height="1510" alt="image" src="https://github.com/user-attachments/assets/588a0bab-70c8-4e1c-a183-0f63e79fa49f" />
관리자 데이터 관리 화면은 관리자가 시스템의 재활용 품목 정보, 상세 가이드, 지역별 API 보정 데이터를 관리하는 화면이다. 관리자는 품목 관리, 재활용 가이드 관리, 지역별 API 보정 관리 메뉴를 통해 데이터를 추가, 수정, 삭제할 수 있다.

예를 들어 새로운 재활용 품목이 추가되거나 품목별 분리배출 안내가 변경된 경우, 관리자는 해당 정보를 수정하여 시스템에 반영한다. 또한 공공데이터 API 결과를 보완해야 하는 지역 정보가 있는 경우 지역별 보정 데이터를 등록할 수 있다.

**사용방법**  
1. 관리자는 품목 정보, 재활용 가이드, 지역별 API 보정 데이터를 추가, 수정, 삭제할 수 있습니다.
2. 변경한 내용은 Supabase 데이터베이스에 저장됩니다.
